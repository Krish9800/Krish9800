## Mission & Engineering Philosophy

I engineer software and defensive architectures at the intersection of offensive security, detection engineering, and resilient systems design. My philosophy is grounded in evidence-first security: simulate real-world adversarial tactics to uncover architectural blind spots, then build stateful detection pipelines, immutable audit mechanisms, and hardened access controls to eliminate them.

Every project in this portfolio is an operational, tested software artifact designed to demonstrate practical defensive capabilities, reproducible setups, clean architectures, and strict adherence to security standards (NIST SP 800-207, MITRE ATT&CK, RFC 9106, RFC 6238, and CISA KEV).
